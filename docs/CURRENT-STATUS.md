# Nihongo 프로젝트 상태

이 문서는 현재 구현 범위와 외부 설정이 필요한 기능, 남은 제약을 구분합니다. 기능 사용법과 실행 명령은 [README](../README.md), 데이터 흐름은 [아키텍처](ARCHITECTURE.md)를 참고합니다.

## 현재 상태

일상 학습, 복습, 검색, 시험, AI 연습을 사용할 수 있는 PWA입니다. Firebase와 외부 API를 설정하지 않아도 로컬 학습 기능은 동작합니다.

## 구현된 사용자 흐름

### 학습과 복습

- 가나·한자·단어·문법 학습
- SM-2 기반 복습 일정과 오답 기록
- 회화·독해·JLPT 모의고사
- 일일 미션, 연속 학습, XP와 레벨
- 단어와 회화 표현 통합 검색

### AI 연습

- Gemini 기반 튜터 채팅
- 작문 첨삭과 독해 지문 생성
- 역할별 회화 연습

Gemini 키가 없거나 요청이 실패하면 기본 학습 화면은 유지하고 AI 기능에 설정 안내를 표시합니다.

### 발음과 오프라인 사용

- Murf.ai 음성 합성
- 메모리와 IndexedDB를 이용한 발음 캐시
- 카테고리 단위 발음 미리받기
- Murf.ai를 사용할 수 없을 때 브라우저 TTS로 전환
- PWA 설치와 온라인 상태 안내

IndexedDB를 사용할 수 없는 환경에서는 음성 캐시를 생략합니다. 캐시 오류가 학습 화면을 중단하지는 않습니다.

### 계정과 동기화

- Firebase 이메일·Google 로그인
- 카카오·네이버 OIDC 로그인 연결 지점
- localStorage의 즉시 복구용 학습 상태
- Firestore의 사용자별 학습 데이터 동기화
- 로그아웃 시 사용자 데이터와 기기 설정 분리

카카오·네이버 로그인은 Firebase Console과 각 제공자 설정이 완료된 환경에서만 사용할 수 있습니다.

### 화면과 개인화

- 마스코트 3종과 의상
- 테마 7종, 홈 레이아웃 4종, 다크 모드
- 주간 기록, 히트맵, 숙련도와 약점 차트
- 업적과 즐겨찾기
- 모바일 중심 반응형 화면

## 검증 범위

```bash
npm run lint
npm test
npm run build
```

Vitest는 SRS 일정 계산, 정답 판정, 콘텐츠 중복, 빠른 검색, IndexedDB 음성 캐시 실패 처리를 확인합니다.

현재 저장소에는 Playwright E2E 실행 명령이 없습니다. 로그인 제공자별 실제 인증과 설치형 PWA의 오프라인 전환은 브라우저에서 수동으로 확인합니다.

## 외부 설정이 필요한 기능

| 기능 | 필요한 설정 | 미설정 시 동작 |
|---|---|---|
| 계정 동기화 | Firebase 환경 변수와 프로젝트 설정 | 로컬 저장만 사용 |
| AI 튜터 | Gemini API 키 | 설정 안내 표시 |
| Murf.ai 발음 | Murf.ai API 키 | 브라우저 TTS 사용 |
| Sentry | DSN | 오류 전송 생략 |
| 카카오·네이버 로그인 | 제공자 앱과 Firebase OIDC 설정 | 해당 로그인 사용 불가 |

## 남은 제약

- 외부 로그인 제공자의 전체 흐름은 배포 환경 설정에 영향을 받습니다.
- 브라우저 TTS의 음질과 지원 음성은 운영체제마다 다릅니다.
- IndexedDB 저장 공간은 브라우저 정책에 따라 축출될 수 있습니다.
- AI 응답의 품질과 지연 시간은 외부 모델 상태에 영향을 받습니다.
- 실제 기기의 PWA 설치·백그라운드 복귀·오프라인 전환을 자동화한 E2E는 아직 없습니다.

## 다음 개선

1. Playwright로 학습 시작부터 결과 저장까지의 기본 흐름을 자동화합니다.
2. Firebase Emulator를 사용해 로그인·동기화 실패와 재시도를 재현합니다.
3. 설치형 PWA의 오프라인 재실행과 캐시 복구를 실제 모바일 환경에서 정기 점검합니다.
4. 문서의 기능 목록과 테스트 수를 코드에서 갱신하는 검사를 추가합니다.
