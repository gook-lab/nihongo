## 팁

1. **한 캐릭터씩 연속으로 생성** - 스타일 일관성 유지
2. **4개 결과 중 가장 자연스러운 것 선택**
3. **정사각형 비율** 선호 (앱에서 원형으로 crop됨)
4. **너무 복잡한 배경 피하기** - 캐릭터가 잘 보여야 함
